# Learn — User Stories (реализованные флоу)

> Отражает фактически реализованные роуты и компоненты на ветке `feat/learn-all-ui`.

---

## SRS (карточки повторения)

**Точки входа:**
- Глобальный навбар «Учусь» → `/learn` (хаб) → карточка «Повторение» → `/learn/srs`
- Learn-саб-навбар «Повтор» → `/learn/srs` (с любого экрана `/learn/*`)

**Последовательность:**
1. Пользователь кликает «Учусь» в хедере → попадает на хаб `/learn`
2. Видит карточку «Повторение 🔁» в гриде → кликает → `/learn/srs`
3. `SrsSession` загружает карточки с `/api/srs/due`
4. Карточка показывает слово → Space/Enter переворачивает
5. Пользователь выбирает оценку (Again/Hard/Good/Easy, клавиши 1–4)
6. По завершении сессии → `SrsSession` вызывает `onFinish` → `router.push('/')` к хабу Learn
7. Незалогиненный: `SrsSession` показывает CTA «Войти»

## Дерево уроков (Course / Path)

**Точки входа:**
- Хаб `/learn` → карточка «Курс 🌳» → `/learn/path`
- Learn-саб-навбар «Курс» → `/learn/path`

**Последовательность:**
1. Хаб → «Курс» → `/learn/path` — рендерит `SkillTree`
2. Клик по узлу урока (в `SkillTree`) → `/learn/lesson/[slug]`
3. `ExercisePlayer` (на странице урока) воспроизводит упражнения
4. Кнопка «к дереву» в `ExercisePlayer` → обратно на `/learn/path`
5. Learn-саб-навбар «Курс» активен на всех `/learn/path` и `/learn/lesson/*`

## Читалка — список текстов

**Точки входа:**
- Хаб `/learn` → карточка «Читалка 📖» → `/learn/reader`
- Learn-саб-навбар «Читалка» → `/learn/reader`

**Последовательность:**
1. Хаб → «Читалка» → `/learn/reader`
2. `TextList` загружает тексты с `/api/texts`, фильтр по CEFR-уровню (A1/A2/B1/B2)
3. Клик по тексту → `/learn/reader/[slug]`

---

## Читалка — текст с кликабельным переводом

**Точка входа:** список текстов → клик по тексту → `/learn/reader/[slug]`

**Последовательность:**
1. `ReaderView` загружает текст с `/api/texts/[slug]`, токенизирует слова
2. Клик по бурятскому слову → `WordPopup` открывается над словом (десктоп) или снизу (мобайл)
3. В `WordPopup`:
   - Загружает перевод с `/api/words/[slug]`
   - Кнопка «Сохранить в SRS» → POST `/api/srs/words`
   - Кнопка «Знаю/Не знаю» → оптимистичное обновление + PUT `/api/reader/words/[id]/known`
   - При отсутствии перевода → ссылка «Предложить перевод» → `/learn/contribute?word=[slug]`
   - Ссылка «Открыть в словаре» → `/words/[slug]`
4. Кнопка «Назад» в тулбаре ридера → `/learn/reader`
5. Learn-саб-навбар «Читалка» активен на всех `/learn/reader/*`

## Лидерборд

- Learn-саб-навбар «Рейтинг»

2. Кнопка «к обучению» (в leaderboard) → `/learn`

## Вклад (Contribute)

**Точки входа:**
- Хаб `/learn` → карточка «Вклад ✍️» → `/learn/contribute` (гость → `/signin`)
- Learn-саб-навбар «Вклад»
- `WordPopup` → «Предложить перевод» → `/learn/contribute?word=[slug]`

**Последовательность:**
1. → `/learn/contribute`
2. `ContributionForm` (табы: новое слово / перевод / исправление) → POST `/api/contributions`
3. Ниже формы — `MyContributions`: история вкладов пользователя с их статусами (pending/approved/rejected)
4. Кнопка «Повторить» на отклонённом вкладе → повторная отправка

**Канон:** `/learn/contribute` — единственное место для вклада. Вкладка «Мой вклад» из профиля удалена.

## Модерация (RBAC — только moderator/admin)

**Точки входа:**
- Хаб `/learn` → карточка «Модерация 🛡️» (видна только при ролях moderator/admin)
- Learn-саб-навбар «Модерация» (аналогично)

**Последовательность:**
1. → `/admin/moderation`
2. Таблица вкладов к рассмотрению, кнопки Approve / Reject
3. Прямой заход без роли → бэк возвращает 403

**Условие показа:** `roles.some(r => r.slug === 'moderator' || r.slug === 'admin')`

## Навигационные инварианты

- **Глобальный хедер**: «Учусь» активен на всех `/learn/*`
- **Learn-саб-навбар**: sticky под хедером (`top: var(--header-h)`), рендерится в `app/[locale]/learn/layout.tsx`
  - Десктоп: горизонтальный ряд
  - Мобайл: нижний таб-бар (Хаб/Повтор/Курс/Читалка + «Ещё» → Рейтинг/Вклад/Модерация)
- **Full-bleed экраны**: reader-view и другие сами управляют sticky-тулбаром; layout добавляет только суб-навбар сверху
