## What's new

The on-screen Buryat keyboard is now available in the translator, dictionary search, corpus search and the phrase explainer. The "һ" key now types the real letter һ instead of a Latin h.

## How to use

1. Press the keyboard button next to the input field.
2. Tap letters — they are inserted where the cursor is.

## How it works

If a Latin h is typed next to Cyrillic letters (for example "hайн"), it is replaced with "һ" when you search or translate.
